# eval

The offline evaluation: 100 public clips, the scripts that produce the tracks, scores and triage
verdicts, and the generated `REPORT.md`. Everything here imports the `remy` package, so run
`pip install -e .` first.

## Files

- `labels.csv` — 100 clips: 40 falls, 60 non-falls, with `type` (fall:standing, fall:chair, fall:bed,
  fall:floor-sit, fall:slow, fall:onto-bed, adl:lie-bed, adl:lie-floor, adl:sit, adl:bend-pick,
  adl:exercise-floor, adl:exercise-stand, adl:get-up, adl:sit-walk) and `lighting` (day / night / lights-off).
  `build_labels.py` regenerates it from the raw downloads.
- `raw/` — downloads (UR Fall cam0 RGB zips, GMDCSA24 mp4s). Untrusted data; nothing executes from here. Not committed.
- `clips/` — 10 fps H.264 clips, max width 640, what SAM sees. `clips_5fps/` holds the round-1 versions. Not committed.
- `out/sam/`, `out/yolo/` — per-clip tracks (committed, so the scores can be re-run without API calls).
  `out/scores/<tracker>_<scorer>/` — per-clip score results plus `_summary.json`. `out/spark/sam_v2/` — Spark verdicts.
  `out/sam_5fps/`, `out/yolo_5fps/` and the matching score dirs are round 1.
- `REPORT.md` — generated by `report.py`. `SENSITIVITY.md` — generated by `sensitivity.py`.

## Scripts

| script | does |
|---|---|
| `build_labels.py` | raw downloads → `labels.csv` (UR Fall types are inferred from the published depth features) |
| `prepare_clips.py` | raw → `clips/` (ffmpeg, 10 fps, max width 640) |
| `sam_tracks.py` | SAM 3.1 over every clip → `out/sam/` (one API call per clip, 50-frame minimum billing) |
| `yolo_tracks.py` | YOLO11n-pose + greedy IoU linking over every clip → `out/yolo/` (local, free) |
| `score_tracks.py --tracker sam\|yolo --scorer v2\|v1\|trigger` | rule scores → `out/scores/` |
| `spark_triage.py --score-dir sam_v2` | Muse Spark triage of the flagged clips → `out/spark/` |
| `report.py` | assembles `REPORT.md` |
| `sensitivity.py` | re-scores the committed SAM tracks over a grid of score-v2 thresholds → `SENSITIVITY.md` (free) |
| `make_gifs.py` | annotated GIFs for a clip (needs `pip install -e ".[eval]"`) |
| `run_all.sh` | the whole chain, in order |

Re-scoring is free and deterministic:

```sh
python eval/score_tracks.py --tracker sam --scorer v2
python eval/score_tracks.py --tracker yolo --scorer trigger
python eval/report.py
```

## Data sources

- UR Fall Detection Dataset (Kwolek & Kępski 2014), CC BY-NC-SA 4.0 — https://fenix.ur.edu.pl/mkepski/ds/uf.html
- GMDCSA24 (Alam et al. 2024), MIT — https://github.com/ekramalam/GMDCSA24-A-Dataset-for-Human-Fall-Detection-in-Videos

Data quirks: UR Fall cam0 mp4s are side-by-side RGB+depth, so the zips of PNG frames are used; the clips end right
after impact, so the hold check is often "unknown"; a seated bystander appears in the UR Fall frames, which is
why the primary track is the most-moving object.
